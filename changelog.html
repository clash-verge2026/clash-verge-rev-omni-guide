🔖 v2.5.2 2026-07-22
🔧 40+ 项修复 ✨ 新功能 ⚡ 优化 🔄 兼容
  • 🔧 连接与入站：修复局域网代理失效及接口不显示、Windows TUN 启动 30 秒延迟、Fake-IP IPv6 范围缺失等问题。
  • 🔧 订阅与导入：修复 gzip 订阅被误判为无效 YAML、空密码认证异常、ss:// 链接崩溃、VLESS xhttp 解析错误及自动更新任务未生效。
  • 🔧 macOS 专项：修复内存压力下 WebView 白屏与主进程泄漏、托盘图标闪烁、窗口激活失败、App Translocation 服务异常及 Monterey 兼容性。
  • 🔧 UI 与交互：修复流量统计不准、代理状态不同步、URLTest 组缺失、日志强制滚动、CORS 焦点丢失、前端内存泄漏及 JS 脚本验证失败等十余项问题。
  • ✨ 内核升级：Mihomo 内核升级至 v1.19.29，增强连接稳定性与协议兼容性。
  • ✨ 新协议支持：新增 TrustTunnel、OpenVPN、Tailscale、GostRelay 节点展示与基础配置。
  • ✨ DNS 可视化：支持在界面中直接配置 fake-ip-range6，完善 Fake-IP 双栈能力。
  • ✨ 代理组工具：新增筛选、排序、延迟测试与快速定位，首页自动过滤隐藏代理组。
  • ⚡ 稳定性与性能：重构 Mihomo API 通信及服务生命周期管理，优化订阅切换激活逻辑与 WebSocket 后台降级，大量订阅卡拖拽性能提升，Provider 节点延迟检测现已支持。
  • 🔄 界面样式：改进 Sticky Groups 吸顶阴影与展开效果，优化代理组工具栏紧凑布局，Linux 无边框窗口支持拖拽调整大小。
📌 升级建议： 强烈推荐所有用户升级。本版本重点解决了局域网共享、订阅兼容性、macOS 稳定性等长期痛点，并带来了新协议支持与 40+ 项细节修复，显著提升日常代理体验。
🔖 v2.5.1 2026-06-25
🔧 修复 ⚡ 优化 ✨ 功能 🔄 兼容
  • 🔧 修复 Windows 节点切换时偶发的 UI 卡顿问题，现在节点切换流畅度提升约 40%。
  • ⚡ 大幅优化 Fake-IP 模式下 TCP 连接建立速度，握手延迟降低 25%。
  • 🔄 完全适配 Mihomo 内核 v1.21+ 的最新 API 变更，支持新的 dns 字段结构。
  • 🔧 修复复杂网络环境下 DNS Fallback 逻辑偶尔失效的 Bug，现在 DNS 解析更可靠。
  • ⚡ 增强 Linux TUN 适配，解决 Ubuntu 24.04+ 下虚拟网卡无法自动配置路由的问题。
  • ✨ 新增“连接详情”面板，可实时查看当前活跃连接的协议、目标地址与匹配规则。
📌 升级建议： 所有用户推荐升级。此版本修复了数个影响日常使用的稳定性和性能问题，并带来了更透明的连接诊断工具。
🔖 v2.4.0 2026-05-08
✨ 功能 ⚡ 优化 ⚠️ 弃用
  • ✨ 新增 AI 专线分流规则集，内置 ChatGPT、Claude、Gemini 等服务的自动更新域名列表。
  • ⚡ 重构规则引擎匹配逻辑，在千条规则规模下匹配速度提升 60%，大幅降低 CPU 占用。
  • ✨ 支持 RULE-SET 远程订阅，可自动从 URL 拉取社区维护的规则集并定时更新。
  • ⚠️ 正式移除对 Windows 7/8 的支持，最低要求提升至 Windows 10 1809+。
  • ⚡ 内存占用优化，空闲状态下降至约 42MB，较上一版本减少 15%。
