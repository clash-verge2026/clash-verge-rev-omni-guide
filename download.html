❓ 下载与安装常见问题

Q: 下载后如何安装？

Windows 用户双击 .msi 或 .exe 安装包，按提示完成安装。macOS 用户打开 .dmg 文件，将应用拖入 Applications 文件夹。Linux 用户可使用包管理器安装 .deb/.rpm，或直接运行 AppImage 文件。

Q: 为什么 Windows 提示“无法验证发布者”？

由于应用未使用商业代码签名证书，Windows SmartScreen 可能会弹出警告。请点击“更多信息”然后选择“仍要运行”。我们确保所有安装包均未篡改，你也可以通过 GitHub Releases 页面校验 SHA256 哈希值。

Q: 如何校验下载文件的完整性？

在 GitHub Releases 页面 的 “Assets” 部分，每个文件均附有 SHA256 校验和。下载后使用命令行工具（如 certutil 或 shasum）进行比对。
