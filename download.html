📌 三步完成安装与首次代理

1

下载并安装

根据你的操作系统选择上方对应的安装包。Windows 双击 .msi，macOS 拖入应用程序文件夹，Linux 使用包管理器或直接运行 AppImage。

2

导入订阅或配置

启动后进入“订阅”界面，粘贴你的 Clash 兼容订阅链接。如果没有订阅，也可手动编写 config.yaml 文件放入配置目录。

3

选择节点并开启系统代理

在节点列表选择一个服务器，点击“系统代理”开关或启用 TUN 模式即可。建议初次使用保持默认的“规则模式”。

🔐 校验文件完整性 (SHA256)

为确保下载的文件未被篡改，我们强烈建议核对 SHA256 校验和。每个安装包在 GitHub Releases 页面均附有对应的 .sha256 文件。

Windows PowerShell 校验命令：

Get-FileHash -Path "Clash.Verge_2.5.1_x64-setup.msi" -Algorithm SHA256

macOS / Linux 校验命令：

shasum -a 256 Clash.Verge_2.5.1_aarch64.dmg

请将输出结果与 Releases 页面 公布的哈希值逐一比对。任何不匹配都可能意味着文件损坏或已被篡改。

❓ 下载与安装常见问题

Q: 下载后 Windows 提示“无法验证发布者”怎么办？

这是因为我们尚未使用昂贵的商业代码签名证书。请点击“更多信息”然后选择“仍要运行”。你可以通过上述 SHA256 校验确保文件是官方的。我们保证所有构建产物均未经过第三方修改。

Q: macOS 提示“无法打开，因为无法验证开发者”如何解决？

前往“系统偏好设置” → “安全性与隐私” → “通用”，点击“仍要打开”。或者使用终端命令 xattr -d com.apple.quarantine /Applications/Clash\ Verge\ Rev.app 移除隔离属性。

Q: Linux AppImage 无法运行或提示权限错误？

请确保 AppImage 文件具有可执行权限：chmod +x Clash*.AppImage。如果系统缺少 FUSE，可尝试使用 --appimage-extract-and-run 参数，或安装 libfuse2。

Q: 我应该选择哪个架构的安装包？

如果不确定，Windows 用户通常选 x64 (64位)。macOS 用户若为 M1/M2/M3/M4 芯片选 Apple Silicon，否则选 Intel。Linux 用户可通过 uname -m 查看架构（x86_64 选 x64，aarch64 选 arm64）。

Q: 安装完成后如何彻底卸载？

Windows 通过“控制面板”卸载；macOS 将应用移至废纸篓并删除 ~/Library/Application Support/io.github.clash-verge-rev.clash-verge-rev 文件夹；Linux 使用包管理器移除或直接删除 AppImage 及 ~/.config/clash-verge-rev 目录。
