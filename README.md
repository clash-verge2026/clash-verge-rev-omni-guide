# ⚡ Clash Verge Rev 是什么？

Clash Verge Rev 是基于 Tauri 与 Mihomo 内核开发的新一代代理客户端。

支持：

- Windows
- macOS
- Linux

核心能力：

- Mihomo 内核
- TUN 模式
- Fake-IP
- DNS 防泄漏
- Rule 智能分流
- GEO 数据更新
- WebDAV 同步
- AI 网站代理

相比 Clash for Windows：

- 更低内存占用
- 更快启动速度
- 更稳定 TUN 模式
- 更强 DNS 模块
- 持续维护更新
