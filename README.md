</details>

<details>
<summary>🤖 How to proxy ChatGPT, Claude etc.?</summary>

## ❓ 常见问题

<details>
<summary>🔁 如何自动更新订阅和规则集？</summary>

配置 [GitHub Actions 工作流](https://github.com/clash-verge2026/clash-verge-rev-omni-guide/wiki/GitHub-Actions)，实现定时拉取最新代理订阅与规则文件，无需手动操作。
</details>

<details>
<summary>🌐 Fake‑IP 模式下部分网站打不开？</summary>

检查 DNS 与 Fallback 设置，确保国内域名正确回落。详细配置见 [DNS 防泄漏指南](https://github.com/clash-verge2026/clash-verge-rev-omni-guide/wiki/DNS-Anti-Leak) 和 [Fake‑IP 架构说明](https://github.com/clash-verge2026/clash-verge-rev-omni-guide/wiki/Fake-IP)。
</details>

<details>
<summary>🎮 TUN 模式如何加速游戏并处理 UDP？</summary>

参考 [TUN 深度优化](https://github.com/clash-verge2026/clash-verge-rev-omni-guide/wiki/TUN-Deep-Dive) 中的混合栈与零拷贝配置，确保游戏流量正确代理。
</details>

<details>
<summary>🤖 如何让 ChatGPT、Claude 走代理？</summary>

使用 [AI 网站智能分流](https://github.com/clash-verge2026/clash-verge-rev-omni-guide/wiki/AI-Proxy-Split) 规则，自动识别并代理主流 AI 服务。
</details>

<details>
<summary>📑 规则不生效或分流异常怎么办？</summary>

优先查看 [配置精要](https://github.com/clash-verge2026/clash-verge-rev-omni-guide/wiki/Configuration-Essentials) 理解规则优先级，并检查 RULE‑SET 是否成功加载。
</details>
