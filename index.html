什么是 Clash Verge Rev

Clash Verge Rev 是基于 Rust 与 Tauri 技术栈开发的新一代 Mihomo 图形化客户端，支持现代化规则分流、TUN 流量接管、多订阅同步、WebDAV 配置管理以及智能代理控制。相比传统 Clash for Windows，Clash Verge Rev 拥有更低资源占用、更强扩展能力以及更现代的 UI 架构。

Mihomo Core

内置现代化 Mihomo 代理核心，支持 RULE-SET、GEOIP、Sniffer、Fake-IP 与脚本扩展能力。

TUN 模式

支持 Windows Wintun、macOS Network Extension 与 Linux Tun Device 系统级流量接管。

规则分流

支持 Rule、Global 与 Direct 模式，适用于智能代理、游戏加速与多区域网络访问。

FAQ 常见问题

Clash Verge Rev 是否支持 Win7？

v2.5.1 起不再支持 Windows 7，建议升级至 Windows 10 或 Windows 11。

TUN 模式无法启动怎么办？

建议以管理员身份运行客户端，并检查 Wintun 驱动与系统网络组件是否正常。

Clash Verge Rev 与 Clash for Windows 有什么区别？

Clash Verge Rev 基于 Rust + Tauri 架构开发，资源占用更低，Mihomo 支持更完善。
