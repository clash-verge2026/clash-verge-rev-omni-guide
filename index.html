⚡ 六大核心优势

Clash Verge Rev 在性能、安全、易用性上全面超越传统代理客户端。每一项特性都经过精心设计，从底层内核到上层交互无缝协同。

🧠

Mihomo 内核驱动

原生支持 RULE-SET、Fake-IP、Sniffer、SSH 隧道等全部 Meta 高级特性。相比 Clash Premium，内存占用降低约 40%，并发处理能力提升 60%。内核热更新无需重启客户端，配置即时生效。紧密跟随上游 Mihomo 发展，始终保持最新协议支持。

🔗

TUN 模式系统接管

一键创建虚拟网络接口，自动接管所有 TCP/UDP/ICMP 流量。支持 mixed 协议栈——TCP 使用高性能系统栈，UDP 使用用户空间 gVisor 栈，兼顾吞吐量与兼容性。终端命令、Docker 容器、游戏、虚拟机流量均可精准路由，延迟增加通常小于 5ms。

🛡️

DNS 防泄漏终极方案

Fake-IP 模式将所有域名解析映射至虚拟 IP 段（198.18.0.x），本地不发起真实 DNS 请求。配合 DoH/DoT 加密远程解析与 fallback 过滤器，即使代理隧道中断，真实 DNS 查询也不会泄露给运营商。国内 DNS 分流解析，国内外网站访问互不干扰。

📑

智能规则分流引擎

支持 DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD、GEOIP、IP-CIDR、PROCESS-NAME 等十余种匹配类型。规则优先级可自定义，并支持 RULE-SET 远程订阅，实现社区规则实时同步。国内外流量自动识别分流，精准高效且无需频繁手动切换。

🤖

AI 网站专线代理

内置 ChatGPT、OpenAI API、Claude、Gemini、GitHub Copilot 等 AI 工具的专属分流策略。自动识别 AI 域名并通过低延迟节点转发，确保开发与研究工作流永不中断。支持 RULE-SET 方式引入社区维护的 AI 域名列表，实现自动更新。

开源社区驱动，每两周迭代。紧跟 Mihomo 内核更新，及时修复安全漏洞。GitHub Issues 响应迅速，文档持续完善。任何人可审计源代码，确保无后门、无遥测。发布包通过 GitHub Actions 自动化构建，构建日志公开可追溯。

常见疑问

❓ 常见问题解答

快速解答你最关心的问题。如果没有找到答案，欢迎前往 GitHub Issues 提问。

Q: 支持 Windows 7 或 Windows 8 吗？

自 v2.5.1 起，Clash Verge Rev 不再支持 Windows 7 / 8。请使用 Windows 10 或 Windows 11 以获得完整功能和安全性更新。如需在旧系统上使用，可尝试历史版本 v2.4.x。

Q: TUN 模式无法启动，提示驱动错误？

请以管理员身份运行客户端，并确保已安装 Wintun 驱动（Windows）或 tun.kext（macOS）。Linux 用户请确认内核已加载 tun 模块，可执行 modprobe tun 检查。

Q: 与 Clash for Windows 有什么区别？

Clash Verge Rev 拥有更低的资源占用（约 45MB vs 120MB）、更现代的 Mihomo 内核、更稳定的 TUN 支持，并且社区持续活跃更新。CFW 已停止维护，而 Clash Verge Rev 每两周发布新版本，紧跟生态发展。

Q: 如何确认 DNS 是否已防泄漏？

可使用 ipleak.net 或 dnsleaktest.com 进行检测。如果配置正确，页面上显示的 DNS 服务器应全部为代理节点 IP，而非你的本地运营商 DNS。推荐使用 Fake-IP 模式配合 DoH/DoT 实现最强防护。

Q: 如何参与项目贡献？

欢迎前往 GitHub 仓库 提交 Issue、PR，或完善 Wiki 文档。任何形式的贡献——代码、翻译、文档、Bug 反馈——都备受感激。

Q: 订阅链接导入后节点为空怎么办？

请检查订阅链接是否有效（可在浏览器中直接访问测试），确认链接格式为 Base64 编码或直接返回 YAML/URI 格式。部分机场需要添加 User-Agent 伪装，可在订阅设置中尝试追加 &flag=clash 参数。

Q: 开启代理后部分国内网站变慢如何解决？

建议使用规则模式而非全局模式。在配置中确保国内域名（如 .cn、.com.cn）使用 DIRECT 策略，同时国内 DNS 使用如 https://doh.pub/dns-query 等国内 DoH 服务器，避免国内流量绕行海外代理。

Q: 客户端会收集我的个人数据吗？

完全不会。Clash Verge Rev 践行零遥测、零追踪原则。所有数据处理均在本地完成，无任何后台上报行为。源代码完全开源可审计，构建日志公开可追溯。如果你担心安全问题，可以自行审查代码并构建。
