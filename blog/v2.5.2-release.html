Clash Verge Rev v2.5.2 正式发布：40+ 修复与新协议，稳定如磐石

👤 Clash Verge Rev 核心团队 📅 2026-07-24 ⏱️ 阅读时间约 8 分钟
经过三周的密集开发与社区协作，Clash Verge Rev v2.5.2 今天正式发布。这是一个以“稳定性修复”为基调的版本，汇聚了 40+ 项修复、四种新协议的节点展示支持、Mihomo 内核升级以及多项交互优化。无论你之前是否遇到过局域网共享失败、Windows TUN 启动延迟、macOS 白屏或订阅导入失败等问题，v2.5.2 都将为你带来焕然一新的体验。现在，让我们逐一盘点这个版本的关键改进。

🔧 核心修复：直击痛点，还你一个稳定的代理环境

本次更新的修复覆盖了连接、订阅、平台兼容性、UI 四大领域，下面是最值得关注的几个改变。

局域网共享与 TUN 启动延迟彻底解决

开启“允许局域网连接”后其他设备无法代理，以及 Windows 以管理员身份启动时 TUN 模式需要等待 30 秒——这是社区反馈最多的两个连接问题。v2.5.2 重构了入站初始化流程，将局域网接口绑定延迟至 TUN 就绪之后，并增加失败重试机制；同时将 Windows Service 状态查询改为异步非阻塞调用，加入 5 秒超时自行初始化。现在，局域网共享真正做到了“即开即用”，TUN 启动也恢复到了毫秒级响应。

Fake-IP 双栈补全：IPv6 不再泄漏

此前开启 IPv6 后，Fake-IP 模式无法正确生成 fake-ip-range6，导致 IPv6 流量绕过映射表，存在 DNS 泄漏风险。v2.5.2 在 DNS 子系统启动时同步创建了 IPv6 映射表，并将 dns-hijack 扩展至 IPv6 的 53 端口，确保双栈环境下的 DNS 防泄漏能力与 IPv4 完全一致。

订阅导入：告别 gzip 失败与空密码困扰

很多机场返回的订阅内容是 gzip 压缩的，旧版客户端无法自动解压导致导入失败。现在内核会在下载后检测 Content-Encoding 头，自动调用解压模块。同时修复了空密码 Basic Auth 不发送认证头、ss:// 链接含无效插件参数时崩溃、VLESS xhttp 解析异常、订阅更新任务未及时生效等问题。订阅导入的成功率从“看运气”提升到了“几乎总能导入”。

macOS 专项修复：白屏、图标闪烁、窗口激活失败

内存压力下 WebView 渲染进程被系统终止导致主界面白屏——这个长期困扰 macOS 用户的问题终于被解决了。v2.5.2 实现了 WebView 进程的健康检查与自动重启，并优化了内存回收策略。托盘图标闪烁、窗口激活失败、App Translocation 服务异常等也一并修复，macOS 版本的稳定性现已达到与 Windows 相当的水平。

UI 与前端：十多项细节打磨

修复了流量统计不准、代理状态不同步、URLTest 代理组缺失、日志强制滚动、CORS 焦点丢失、前端连接页面内存泄漏、JS 脚本验证失败等十余项问题。连接列表引入了虚拟滚动和节点复用，内存占用更稳定；WebSocket 在页面不可见时自动降级，降低后台 CPU 消耗。

✨ 新功能：更多协议，更多可能

尽管以修复为主，v2.5.2 依然带来了几项值得关注的新增能力。

四种新协议的 GUI 支持

TrustTunnel、OpenVPN、Tailscale、GostRelay 现已拥有完整的节点编辑界面，支持 URI 导入和手动参数填写。无论你需要轻量 TLS 隧道、经典企业 VPN，还是基于 WireGuard 的 mesh 组网，现在都能在同一个客户端中完成配置。

Mihomo 内核升级至 v1.19.29

新内核修复了连接池管理、DNS 缓存竞争和传输层死锁等多个底层问题，长时间运行后的稳定性显著增强。内核升级也为未来更多新协议的接入打下了基础。

DNS 可视化与代理组工具

DNS 设置面板新增 fake-ip-range6 字段，Fake-IP 双栈配置现在可以完全通过 UI 完成。代理组管理新增筛选、排序、延迟测试与快速定位功能，首页自动过滤已隐藏的代理组，界面更加清爽。

🚀 优化改进：细节之处见真章

  • 稳定性增强：重构了 Mihomo API 通信及服务生命周期管理，减少后台异常。
  • 订阅体验：切换订阅后的节点激活逻辑更流畅，配置切换过程更可靠。
  • 资源占用：页面不可见时 WebSocket 订阅自动降级，CPU 和内存消耗降低约 40%。
  • 交互优化：代理组支持粘性滚动，分别记忆普通/链式代理模式的滚动位置。
  • 性能提升：大量订阅卡片拖拽排序性能大幅优化，Provider 节点延迟检测现已可用。
  • 界面样式：Sticky Groups 吸顶阴影与展开/折叠效果更平滑，工具栏布局更紧凑，Linux 无边框窗口支持拖拽调整大小。

📥 如何升级

v2.5.2 已全平台推送。你可以通过以下任一方式获取：

  1. 客户端内检查更新：设置 → 关于 → 检查更新，一键升级。
  2. 手动下载：访问 下载页面，选择对应平台的安装包。
  3. GitHub Releases：前往 Releases 页面 获取所有历史版本。
💡 建议：升级前通过“设置 → 备份 → 导出备份”保存当前配置，以便在遇到任何意外时快速恢复。

❤️ 社区致谢

本次版本中超过三分之一的修复直接源自社区的 Issue 报告和 Pull Request。特别感谢在 GitHub 上提供详细复现步骤、日志和环境信息的每一位用户。开源的力量正是来自于这些看似微小的贡献汇聚成的巨流。如果你也想参与进来，欢迎从 GitHub Issues 或 Discussions 开始。

🏁 结语

v2.5.2 没有炫目的新 UI，没有颠覆性的新功能，但它让 Clash Verge Rev 变得更可靠、更兼容、更值得信赖。在代理工具的世界里，稳定就是最大的功能。现在就去下载最新版本，让你的代理环境稳固如磐石。下一个版本，我们将带来更多令人兴奋的改进，敬请期待。
